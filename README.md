## 🏆 Proyectos Destacados

### 🏨 Hotel Gales — Ecosistema Web & Desktop
Sistema integral de gestión hotelera desarrollado en dos plataformas que comparten la misma identidad visual y PostgreSQL como base de datos.

🌐 **[Hotel Gales Web](https://github.com/anfeospa999-oss/hotel-management-system-web)**
- **Stack:** Python, Flask, PostgreSQL, Bootstrap.

🖥️ **[Hotel Gales Desktop](https://github.com/anfeospa999-oss/hotel-management-system-desktop)**
- **Stack:** Java 24, Swing, FlatLaf, PostgreSQL, JDBC.

> **Destacado:** Arquitectura MVC, autenticación por roles, CRUD completos, dashboard de estadísticas y facturación.
